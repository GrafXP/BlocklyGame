# Glossary of game terms

The words the game uses for its own things, in every language, so the interface, the blocks and the missions say the same thing the same way (PLAN.md §8, Languages). Look a term up here before translating a message that contains it, and add terms as they come in. A new language adds a column.

German uses the informal *du* and short imperatives on blocks, like Blockly's own German blocks (“wiederhole %1-mal:”, “falls”, “sonst”). Places and items stand alone on blocks, without an article (“gehe zu Sägewerk”). Nouns keep their capital letters.

| set … to …, change … by … | setze … auf …, ändere … um … | Blockly's own German, but *ändere* rather than its *erhöhe*, since a change can be -1. |
| my block (a block of one's own) | mein Baustein | Blockly's “to do something” and “um etwas tun”. The category is *Meine Bausteine*. |
| input (of one's own block) | Eingabe | “Holz holen mit: Ziel”. |
| message | Nachricht | Named in quotes: „Brett fertig“, „Stein bitte“. |
| send … to …, wait for … | schicke … an …, warte auf … | |
| inbox | Briefkasten | “Der Briefkasten ist voll: Werkstatt”. |

The game's name, *BlocklyBots*, isn't translated (PLAN.md §8). The island in the missions is *Robot Island*, in German *Roboterinsel*.
