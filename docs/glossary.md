# Glossary of game terms

The words the game uses for its own things, in every language, so the interface, the blocks and the missions say the same thing the same way (PLAN.md §8, Languages). Look a term up here before translating a message that contains it, and add terms as they come in. A new language adds a column.

German uses the informal *du* and short imperatives on blocks, like Blockly's own German blocks (“wiederhole %1-mal:”, “falls”, “sonst”). Places and items stand alone on blocks, without an article (“gehe zu Sägewerk”). Nouns keep their capital letters.
